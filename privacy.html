Privacy Policy (English)

"AI Kaidansha Publisher" (the "Tool") is a personal desktop tool operated by the owner of AI Kaidansha (the "Operator"). It is used only by the Operator to upload the Operator's own original videos to the Operator's own YouTube, Instagram and TikTok accounts, and to review the performance of those videos. It is not offered to other users.

YouTube API Services

The Tool uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API). By using the Tool, you agree to be bound by the YouTube Terms of Service（YouTube利用規約）. Google's handling of data is described in the Google Privacy Policy（Googleプライバシーポリシー）.

1. Information we access

Only for the YouTube channels that the Operator has authorized via Google OAuth 2.0:

  • Channel basic information (channel ID, title)
  • OAuth tokens needed to upload videos (stored locally)
  • Statistics of the Operator's own channels and videos (views, watch time, subscribers, traffic sources, audience retention)

The Tool does not access other users' personal data, comments, subscriber lists or messages.

2. How we use the information

  • Uploading the Operator's own videos (as private or scheduled) and adding them to the Operator's playlists
  • Reviewing the performance of the Operator's own videos to improve future productions

3. Storage, sharing and cookies

All data is stored only on the Operator's own computer. It is never sold, shared with, or disclosed to third parties. The Tool is a desktop program and does not use cookies or similar tracking technologies, and it does not collect information from any device other than the Operator's own computer.

4. Retention, revocation and deletion

Statistics are refreshed regularly. Access can be revoked at any time via the Google security settings page: https://security.google.com/settings/security/permissions. After revocation, or on request, all data obtained through YouTube API Services and stored by the Tool is deleted within 30 days.

5. Contact

Questions about this policy: send a message to @ai_kaidansha on Instagram or TikTok.

日本語

「AI怪談社 投稿ツール」（以下「本ツール」）は、AI怪談社の運営者（以下「運営者」）が、自身のYouTube・Instagram・TikTokアカウントに自社制作の動画を投稿し、その成績を確認するためだけに使う個人用のデスクトップツールです。一般の利用者には提供していません。

YouTube API サービスについて

本ツールは YouTube API サービス（YouTube Data API v3、YouTube Analytics API）を使用しています。本ツールを利用することで、YouTube Terms of Service（YouTube利用規約）に同意したものとみなされます。Googleによるデータの取り扱いはGoogle Privacy Policy（Googleプライバシーポリシー）をご覧ください。

1. 取得する情報

運営者がGoogleのOAuth 2.0で連携を許可したYouTubeチャンネルについて、次の情報のみを取得します。

  • チャンネルの基本情報（チャンネルID、チャンネル名）
  • 動画の投稿に必要な認証トークン（運営者のコンピューター内に保存）
  • 運営者自身のチャンネル・動画の統計情報（再生数、総再生時間、登録者数、流入元、視聴維持率）

他のユーザーの個人情報、コメント、登録者の一覧、メッセージは取得しません。

2. 利用目的

  • 運営者自身の動画のアップロード（非公開または予約公開）と、運営者の再生リストへの追加
  • 運営者自身の動画の成績の確認と、今後の制作の改善

3. 保管・共有・Cookie

取得した情報は運営者のコンピューター内にのみ保存し、第三者に販売・提供・共有しません。本ツールはデスクトップのプログラムで、Cookieや類似の追跡技術は使用せず、運営者のコンピューター以外の端末から情報を収集しません。

4. 保存期間・連携の解除・削除

統計情報は定期的に更新します。連携はGoogleのセキュリティ設定ページ（https://security.google.com/settings/security/permissions）からいつでも解除できます。解除後、または依頼があった場合、YouTube API サービスから取得して本ツールが保存した情報は30日以内に削除します。

5. お問い合わせ

InstagramまたはTikTokの @ai_kaidansha へのメッセージでお願いします。
